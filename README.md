# 逆走爺 — 東京から、どこまで。

スマホ向けの3D反射神経ゲーム。HTML / CSS / JavaScript / Three.jsで動く静的サイトです。バックエンド、Unity、外部モデルは使いません。実際の道路で逆走は絶対にしないでください。

## 起動

Node.js 20.19以降（または22.12以降）を用意して実行します。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開きます。同じWi-Fi上のスマホからは、PCのLAN IPと表示ポートを使えます。スタート操作でWeb Audioが有効になります。音は右上で切り替えられます。

```sh
npm test
npm run build
```

`dist/` が静的配信対象です。`npm run build` は `--base=./` を指定するため、GitHub Pagesの `/gyakusouji/` のようなサブパスでも動作します。GitHub Pagesの有効化・公開は行っていません。Pagesを利用する場合は `dist/` の内容を配信してください。Sitesのプレビュー用設定は `.openai/hosting.json` にあります。

## 操作と判定

- スタート後、中央から対向車が1台ずつ出現。左右どちらかへのフリック、または左右矢印キーで回避。
- Pointer Events の `pointermove` が横しきい値を超えた時点で確定。`pointerup` を待たずにカメラと車体が動きます。1ジェスチャー／1台につき1回。空振り入力は持ち越しません。
- `performance.now()` と予定衝突時刻の差で判定。残り時間が正なら即座に回避を確定し、アニメーションや次フレームの時刻に判定を依存させません。
- 800ms超はEARLY（表示距離 +200mのペナルティ、回避は成功）。400ms超〜800msはOK (+0m)、220ms超〜400msはGOOD（表示 −50m）、1ms超〜220msはGREAT（表示 −150m）、0ms超〜1msはCRITICAL（表示 −1,000m）。0ms以下は衝突。
- 車が通過してから中央に復帰し、復帰後650〜1250msを空けて次の車を出します。ボーナスを除いた走行距離で接近速度が上昇します。
- 「東京まで」の表示は0mから始まり、離れるほど −100m、−200m とマイナス方向に増えます。ボーナス表示も GOOD −50m / GREAT −150m / CRITICAL −1,000m。HUD・結果・自己ベストをこの表記で統一しています。内部スコアは走行距離＋ボーナス−ペナルティとし、より遠く（表示ではより小さい値）に進んだ記録を自己ベストにします。既存の保存記録もそのまま引き継ぎます。自己ベストは `localStorage` に保存。保存不可の場合もプレイ可能ですが、再読み込み後には記録を保持できません。
- 右上のⅡで一時停止。タブ切替・ウィンドウのフォーカス喪失でも自動停止し、再開ボタンを押すまで進みません。停止時間は接近期限から除外します。

## 調整・モデル差し替え

`src/config.js` の `earlyThresholdMs`（初期値800ms）と `earlyGrade.penalty`（初期値200m）で早すぎ判定を調整できます。ペナルティは各車1回で、車のいない時の入力には発生せず、難易度にも影響しません。スコアが0未満になった場合は「東京まで +○○m」と表示します。

`src/config.js` に判定幅・加点・車速・難易度上昇率・出現距離・出現間隔・中央復帰時間・回避幅・フリックしきい値・衝突カット時間をまとめています。時間単位はms、距離はm。`src/engine.js` は描画から独立した判定処理です。

`src/models.js` の `makeCar` / `makeGrandpa` / `makeTree` / `makeCockpit` がモデル差し替え箇所です。現在は軽量なプリミティブ形状で再現しています。`src/world.js` が道路と車内カメラ・衝突カット、`src/audio.js` がWeb Audioによる接近音・回避音・衝突音を担当します。音声ミームの録音データは使用していません。タイトルの書体にはGoogle Fontsを利用し、取得できない場合はシステム書体にフォールバックします。Three.jsはビルドに含まれ、CDNに依存しません。

## 確認

`tests/engine.test.js` の9テストで以下を検証しています。

- 左右の回避と入力イベント直後の変位開始
- 通常4評価とEARLYの各境界、加点と回避が各1回であること
- 衝突直前の受理済み入力が描画遅延で失敗に変わらないこと
- 入力遅延時の衝突、予定衝突時刻での距離停止、再スタート
- 中央復帰と次の出現までの待ち時間
- 空振り入力の破棄、ボーナスが接近速度に影響しないこと
- pointermove中のフリック確定、縦操作・別ポインター・重複入力の除外、一時停止中の期限維持

静的ビルド成功。非公開Sitesへの配信成功を確認しました。確認用ブラウザではChatGPT認証画面まで確認し、ゲーム画面の目視検証はできていません。ローカルプレビューは実行環境のポート制限で起動できませんでした。実機のiPhone Safari / Android Chromeでのフリック・描画・音・保存は未検証です。参考動画の添付はこの会話で参照できなかったため、記載された構図・色・演出をもとに制作しています。
